NOTE / 01

How I build

I learn by building first and refining after — get something working on screen, then go back and make it clean. I studied CSS systematically (box model, flexbox, positioning, transitions) and explored DOM manipulation in depth: selectors, event listeners, localStorage, and creating elements dynamically.

NOTE / 02

Consistency without repetition

This whole site is one HTML file, but the navbar and every project card still come from a single source: the nav is written once and reused as anchor links to each section, and the project cards are generated by one JavaScript function reading one data array. So a new project or a nav change only has to be written in one place, not copy-pasted across sections.
